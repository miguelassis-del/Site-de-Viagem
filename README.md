# Euro Viagem 🌍✈️

Site de viagem desenvolvido para praticar fundamentos de **Front-End**, utilizando **HTML5** e **CSS3**. Projeto realizado durante minha formação em Engenharia de Software, com foco em estruturação de páginas, estilização, organização de elementos e construção de interfaces web.

## 🔗 Demo

(https://miguelassis-del.github.io/Site-de-Viagem/).

## 🖼️ Sobre o projeto

O site apresenta uma vitrine de destinos de viagem (Bali, Paris, Roma, Veneza), cada um com imagem, descrição e botões de ação, além de uma seção de miniaturas (thumbnails) navegável por setas.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação semântica das páginas
- **CSS3** — estilização e layout (Google Fonts: Poppins, Roboto Flex, Roboto)
- **JavaScript** — interatividade (navegação entre destinos)

## 📁 Estrutura do projeto

```
Site-de-Viagem/
├── img/          # Imagens dos destinos
├── index.htm     # Página principal
├── script.js     # Lógica de interação (carrossel/navegação)
└── style.css     # Estilos do site
```

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/miguelassis-del/Site-de-Viagem.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Site-de-Viagem
   ```
3. Abra o arquivo `index.htm` diretamente no navegador, ou utilize uma extensão como **Live Server** (VS Code) para melhor experiência de desenvolvimento.
